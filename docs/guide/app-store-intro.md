# ETSPress 多平台扩展插件平台

ETSPress 是一个面向多种建站、发卡与数字商品系统的扩展插件平台。我们将不同平台的主题、机器人、业务工具和接口扩展集中整理，为用户提供清晰的插件介绍、安装指引与使用文档。

ETSPress 不从属于某一个特定系统，也不只服务于 Dujiao Next。平台会根据实际需求持续接入新的系统与插件类型，让不同技术栈、不同业务场景的用户都能找到适合自己的扩展方案。

## 已支持平台

目前 ETSPress 已收录 4 个平台的 13 款扩展插件：

| 平台 | 已上线扩展 | 主要应用场景 |
| --- | ---: | --- |
| WordPress | 2 款 | 网站主题、新闻内容采集与自动发布 |
| Dujiao Next | 5 款 | 商城主题、发卡机器人、授权管理、流媒体合租与页面优化 |
| 异次元发卡 | 4 款 | 商城主题、发卡机器人、上游 API 对接与自动交付 |
| 智简魔方 | 2 款 | 网站主题、订单通知与 Telegram 客户服务 |

已上线内容会继续更新，具体插件及其使用文档请查看左侧的 **已上线插件扩展** 目录。

## 我们解决什么问题

### 对平台用户

- **集中发现扩展**：不用在多个渠道反复寻找插件、主题和配套工具。
- **快速判断适配性**：按目标系统查看可用扩展，减少下载后才发现不兼容的情况。
- **获得完整指引**：从功能介绍到安装、配置和故障排查，逐步补齐实际使用所需文档。
- **扩展现有业务**：通过机器人、主题、授权、内容自动化与 API 对接等能力拓展业务场景。

### 对插件开发者

- **面向多个平台展示产品**：让同一类能力能够触达不同系统的用户。
- **建立统一发布标准**：逐步规范插件信息、版本、兼容范围、更新记录与安装说明。
- **降低重复维护成本**：通过统一的文档结构和发布流程管理跨平台插件。
- **获得持续反馈**：围绕真实使用场景改进兼容性、稳定性与功能体验。

## 插件覆盖方向

ETSPress 不限定单一插件形态，当前及后续重点包括：

- **主题与界面**：商城主题、博客主题和页面体验优化。
- **机器人与自动化**：Telegram 发卡、订单通知、客户服务和内容发布。
- **业务功能**：软件授权、账号合租、营销工具和运营辅助能力。
- **系统连接**：上游 API、商品同步、库存同步和订单自动交付。
- **开发者工具**：插件规范、版本管理、兼容性检查和发布文档。

## 平台原则

1. **多平台优先**：所有产品说明和规划都以支持多种系统为前提。
2. **真实可用**：明确区分已上线能力与规划中能力，不用概念代替交付。
3. **兼容透明**：清楚标注适用平台、版本要求、依赖项和已知限制。
4. **安全可控**：插件应尽量与宿主系统保持边界，安装、停用和卸载过程可追踪。
5. **文档完整**：每款扩展都应提供功能说明、部署步骤、配置方法和常见问题。

## 发展方向

ETSPress 将从现有的插件展示与文档平台，逐步发展为覆盖插件发现、兼容性管理、版本发布和开发者协作的多平台扩展服务。具体建设顺序请查看 [开发计划](/guide/app-store-roadmap)。
